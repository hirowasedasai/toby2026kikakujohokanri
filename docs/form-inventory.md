# 現行フォーム棚卸し

## 目的と状態

参加団体・参加者企画と運営スタッフ企画について、通常提出、その他掲載情報、変更申請の5フォームを別々のフォームとして扱うため、現行仕様を棚卸しする。

この文書にはフォームID、回答者情報、実回答、Spreadsheet IDを記録しない。現行フォームと回答タブは読み取り専用で確認し、質問、選択肢、設定、回答ヘッダーだけを記録する。

2026-08-29時点で既存4フォームの編集画面と、新規管理Spreadsheetへの回答先接続を確認済みである。2026-09-02にその他掲載情報フォームの編集画面を確認した。フォームの質問、選択肢、必須設定、分岐、公開設定はコードから変更しない。

通常提出2タブだけをマスターへ自動同期する。参参通常回答は、マスター同期後に1回答1行で`参参一覧`へ差分同期し、フォーム回答の参参名・企画名を確定版として扱う。同じメールアドレス、参参名、参加企画の回答だけを全件警告し、人が誤回答を専用メニューから除外するまで自動選別しない。参加企画が違う回答は別企画として扱う。その他掲載情報はマスターを経由せず、運スタ通常回答と同じ18列の局別タブへ専用区分として差分同期する。変更申請2タブは回答原本として保持してマスターへ上書きしない。運スタ変更申請の`項目名：「内容」`記法を安全に解析できる場合だけ、通常企画の局別自動管理列へ差分反映し、曖昧な申請は`26要手動確認`へ送る。局別タブの手動6列は変更申請から自動上書きしない。

5フォームは相互に統合せず、それぞれ個別のフォームとして維持する。回答先は同一の新規管理Spreadsheetとし、フォームごとに上表の専用回答タブへ接続する。

- 期限と開催日は2026年の曜日と一致する日付へ更新済み。
